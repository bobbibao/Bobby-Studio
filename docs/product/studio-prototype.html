Try the creative flow

Write a prompt, draw on the canvas, then select Generate. Realtime updates after about 700 ms of quiet input. While a preview is running, only the latest pending draft is kept.

New images are procedural illustrations, not AI inference. This prototype makes no API calls and does not persist after closing the page. Save a version and download it to keep a local copy.

Ctrl/Cmd + Enter generates. With the canvas focused, Ctrl/Cmd + Z undoes; add Shift to redo. Choose Prompt only to create without drawing.
